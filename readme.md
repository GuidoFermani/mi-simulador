# Simulador de Academia Deportiva
Este proyecto permite registrar y administrar jugadores de una academia deportiva.

### Funcionalidades
- Registro de jugadores con nombre, edad, categoría y posición.
- Búsqueda de jugadores por nombre.
- Filtrado por categoría.
- Listado de nombres y posiciones.
- Cálculo de la edad promedio.
- Gestión de jugadores mediante clases, objetos y arrays.

### Cómo ejecutar el proyecto
1. Descargar o clonar este repositorio.
2. Abrir la carpeta `mi-simulador` en Visual Studio Code.
3. Abrir el archivo `index.html` con la extensión Live Server o directamente en el navegador.
4. Seguir las instrucciones que aparecen en pantalla.

La información y los resultados se pueden consultar desde la consola del navegador (F12).
